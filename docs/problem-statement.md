# Employee Leave Management System

## 1. Problem Statement

Managing employee leave manually can be time-consuming and prone to errors. Employees need a convenient way to apply for leave, check their leave balance, and track the status of their requests. Administrators need a centralized system to manage employee records and review, approve, or reject leave applications.

The Employee Leave Management System is designed to provide a structured solution for managing the complete leave request process. The system will provide separate functionalities for employees and administrators while maintaining persistent records of employees and leave requests.

## 2. Objectives

- Provide employee and administrator login functionality.
- Allow employees to apply for different types of leave.
- Maintain and display employee leave balances.
- Allow employees to view and cancel pending requests.
- Allow administrators to approve or reject leave requests.
- Maintain employee and leave records using persistent storage.
- Validate leave requests and prevent invalid or overlapping applications.
- Demonstrate Object-Oriented Programming concepts using C++.
- Provide a simple graphical frontend for interacting with the system.

## 3. Scope

The system will support employee management, leave application, leave approval/rejection, leave balance management, request history, search and filtering, validation, and persistent storage.

The backend will be implemented using C++ and will demonstrate classes, encapsulation, inheritance, polymorphism, virtual functions, templates, exception handling, operator overloading, and smart-pointer-based memory management.

A Python-based frontend will provide a user-friendly interface for employees and administrators.

## 4. Users

### Employee

- Login
- View profile
- View leave balance
- Apply for leave
- View leave requests
- Cancel pending requests
- View leave history

### Administrator

- Login
- Add and remove employees
- Search employees
- View employee information
- View pending leave requests
- Approve or reject requests
- View leave statistics

## 5. Leave Types

- Casual Leave
- Sick Leave
- Earned Leave

## 6. Storage

Employee information and leave requests will be stored persistently using CSV files.
